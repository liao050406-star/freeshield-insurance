# 自由盾 · AI 内容风险保险

公开前端产品演示，包含统一入口、澄鉴客户端及企业管理端。

## 页面

- index.html：统一入口。
- client.html：客户端，内容检测、动态报价、模拟投保、理赔与个人记录。
- enterprise.html：企业端，AI 获客、风险识别、人工核保、保单、理赔与决策审计。

三个 HTML 都是自包含文件，无需安装依赖或运行构建。GitHub Pages 通过 Actions 自动部署。

## 演示边界

AI 功能使用本地规则及演示案例；未对接真实模型、保险机构或支付服务。记录保存在浏览器 localStorage，未使用共享数据库。企业端没有账号鉴权，仅供公开产品演示；请勿输入真实客户或个人敏感信息。

## 更新

替换相应 HTML 并推送 main，GitHub Actions 会重新发布。业务源代码在本地开发项目中维护；该仓库只包含可部署网页。
